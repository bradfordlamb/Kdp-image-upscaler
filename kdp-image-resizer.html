KDP Image Requirements for Print Books

KDP print quality depends heavily on image resolution. Your images should be large enough to print clearly at the size they appear in your book.

Recommended DPI

Aim for at least 300 DPI for print images. Use 600 DPI for detailed covers, line art, maps, and text-heavy graphics.

File formats

PNG is good for illustrations, text, icons, and hard edges. JPEG is good for photographs. Avoid repeatedly saving JPEG files because quality can degrade with each export.

Pixel dimensions matter most

DPI is useful only when connected to physical print size. A high DPI label does not help if the actual image is too small.

Common mistakes

  • Using screenshots as print images.
  • Stretching small images in the manuscript.
  • Compressing images too aggressively.
  • Ignoring cover bleed and trim requirements.
