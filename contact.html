The homepage already shows a way to support the tool: Cash App $BradfordLamb. That cashtag is displayed on the page. This site does not process the payment. Questions about a Cash App payment belong with Cash App.

For a correction to one of the guides, include the page URL and the KDP Help page you are comparing it with. KDP changes trim limits, cover rules, and file checks, and the guides cite specific help topics so an outdated sentence can be checked against the current page.

This site cannot see images you run through the upscaler. If a download fails, the usual causes are on the device: the scaled canvas is too large for the browser, the source DPI is not lower than the target DPI, or the browser blocked multiple downloads. Those cases are described in the resizer guide.
